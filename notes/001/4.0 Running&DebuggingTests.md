# Running & Debugging Tests

## Running Tests
Playwright allows us to run and debug tests
1. Command Line
- Runs tests on headless mode
- Tests run on all browsers as configured on the `playwright.config.ts` file
- Use command `npx playwright test`

2. UI Mode
- Most recommended way allowing a walk through each step of the tests and visually see what is happening before, during and after each step
- Use command `npx playwright test --ui`
- Provides other features such as locator picker and watch mode

3. Headed mode
- Allows tester to visually see how Playwright interacts with the website
- Run tests on different browser. To  specify the browser we want our tests to run on use `--project flag` i.e. 
    - `npx playwright test --project webkit`
    - `npx playwright test --project=webkit`
    - `npx playwright test --project webkit --project chromium --project firefox`
    
- Run specific test `npx playwright test example.spec.ts`
- Run tests in a specific directory `npx playwright test /dir/subDir`
- Run tests with the text "landing" in the file name `npx playwright test landing`
- Run tests with a specific title `npx playwright test -g "Title"` // Title - Description argument in a test block
- Run failed tests (Tests must have failed and being run a second time) `npx playwright test --last-failed`
- To run tests on VsCode
    - Use the VsCode extension
    - Run tests from testing sidebar


## Debugging Tests
Playwright runs in Node.js. Playwright provides several debugging options
- Use `console.log` on the IDE or VsCode Extension
- Use UI Mode. Walk through each step allowing one to see what happens before, during and after each step
- Use Playwright inspector - Step through Playwright API calls, see debug logs and explore locators

1. Debugging in UI Mode
- Good dev exp
- Other features eg locator picker, watch mode
- Use `Pick Locator` button to select and element and see the locator that Playwright would use to find that element
- Edit locator on locator playground an see locator get highlighted in the browser window
- Use `Copy Locator` button to copy locator to your clip board and paste it into your test

2. Debug in Playwright Inspector
- Command `npx playwright test --debug`
    * Allows you to run through the steps, step-by-step using the `Step Over` button
    * Clicking on the `Play` button runs all tests start to finish
    To run a specific file `npx playwright test example.spec.ts --debug `
    To run a test file starting from a specific line `npx playwright test example.spec.ts:20 --debug`

## Test Reports
- When a test ends a report is created. When a test fails, the reports opens by default.
- To open the report manually, run the command `npx playwright show-report`
- Playwright Test reports allow filtering by browser and pass state
