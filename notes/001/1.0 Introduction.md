# Getting Started with Playwright

Playwright is an end-to-end (E2E) testing framework.
Bundles test runner, assertions, isolation, parallelization and rich tooling

## Installing
`npm init playwright@latest`
When this command is run on the terminal, user is prompted
1. To use Typescript or Javascript (defaults to TS)
2. What folder to put your tests - (defaults to `tests` otherwise defaults to `e2e`)
3. Whether to include GitHub actions (Recommended for CI/CD)
4. Whether to install Playwright browsers (optional and can  be installed later via npm install)

:Note: Can be run both on a new and existing project without overwriting existing tests
When the `npm init playwright@latest` is run several files are automatically created;
- `playwright.config.ts` - Centralizes all configurations
    configurations - timeouts, retries, projects,  reporters, target browsers
- `package.json` - dependencies, devDependencies
- `package-lock.json`
- `tests/ example.spec.ts` - Sample spec file


## Running tests
`npx playwright test` - Tests run in parallel across Webkit, Chromium and Firefox
Execute Playwright tests in headless mode, where the browser runs without a graphical user interface (GUI). This mode is faster and consumes fewer resources, making it ideal for CI/CD pipelines and automated testing environments.

### Playwright Browsers ###
1. Chromium - Web browser that Google Chrome is built on
2. Webkit - Web browser engine used by Safari
3. Firefox - Web browser provides privacy, focus, choice and independence

- See a browser window `npx playwright test --headed`
- Run on a specific project `npx playwright test --project=chromium`
- Run a specific file `npx playwright test test/example.spec.ts`
- Open the testing UI `npx playwright test --ui`


## Displaying HTML report
When tests run is complete, a HTML report is generated showing what tests run against their pass/fail status
`npx playwright show-report`

## Updating Playwright
To update Playwright and install new browser binaries and dependencies
`npm install -D @playwright/test@latest`
`npx playwright install --with-deps`

## Checking the version
`npx playwright --version`
