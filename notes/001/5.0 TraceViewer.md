# Trace Viewer

Think of trace like a screen recording on the tests as they run
Playwright provides `Trace Viewer`, a GUI tool that allows you to explore recorded Playwright traces
With TraceViewer, testers can go back and forward through each action.

1. Recording a Trace
- Traces are set up - on the `playwright.config.ts` file - to run on the first retry. By default, # of reties set on config file are 0 - locally and 2 - CI. 
- Traces are therefore not mainly used in local testing and UI Mode is used instead.
- To force trace locally, run the command `npx playwright test --trace on`

2. Open HTML report
npx playwright show-report

3. Open the Trace
- Next to the file name, click the `View Trace` icon/ button
- Expand tests and scroll to `Traces` tab

4. View Trace
To view the trace, *click through actions* or *hover using the timeline*
