# Generating Tests

Playwright allows us to generate tests automatically.
Launching codegen opens
1. Browser window - For interaction
2. Playwright inspector - for recording, copying and managing your generated tests

`npx playwright codegen https://example.demo`
The URL is optional and can be added in the browser window

### Recoding a test
1. Run codegen and perform actions on the browser window
2. Playwright will generate code for your actions automatically
3. Codegen analyzes the rendered page and recommends the best locator
    - Prioritizes on the role, text and test-id locators
    - For multiple pages matching a given locator, generator improves it to uniquely identify the target element reducing test failure and flakiness

Test generator can record
1. Actions
2. Assertions - assert visibility, text OR value

To stop recording, click on the `Record` button
To clear the generated code and start afresh, click on the `Clear` button

## Generating locators
1. Click on the `Record` button to stop recording
2. Click on the `Pick Locator` button
3. ... and ,on the browser window, hover on the desired elements
4. Click on the `Copy` button to copy the locator
5. Edit the locator to match your need

### Emulation
Playwright test allows test generation for specific viewports, devices, color schemes, geolocation, language or timezone
Also allows tester to preserve authentication state
